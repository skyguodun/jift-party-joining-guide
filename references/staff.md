# 教职工入党专属流程（江西服装学院）

> 适用对象：江西服装学院在职教职工（含教学、教辅、管理、工勤岗位）。依据《中国共产党发展党员工作细则》（2026修订版）第八条"采取党员推荐、群团组织推优等方式"确定入党积极分子，并参考多所高校教职工发展党员实施细则（信阳师范大学外国语学院、烟台汽车工程职业学院、湖南大学在中青年教师中发展党员实施意见等通行做法）整理。具体以江西服装学院党委组织部最新通知为准。

## 一、与学生渠道的核心区别

| 维度 | 学生 | 教职工 |
|------|------|--------|
| 产生方式 | 团支部推优大会（28岁以下团员） | **党员推荐 + 群团组织推优**；28岁以上已退团者不再进行团员推荐，走党员推荐 |
| 名额口径 | 每班不超过 2 名 | 无"每班名额"，由支部按"控制总量、优化结构"统筹，成熟一个发展一个 |
| 核心考核 | 学业成绩（不及格≤2门）、青年大学习、德育分 | **师德师风、本职工作业绩、服务奉献、群众公认（同事测评）、遵纪守法** |
| 民主测评对象 | 同学 | **同事 / 教职工** |
| 群众座谈会 | 同学座谈会 | **同事座谈会** |
| 材料归档 | 学生档案 | 有本人事档案的，归入人事档案 |

> 共同点：五阶段25步骤、培养期≥1年、党委审批3个月内（最长6个月）、预备期1年、全程2.5—3年，这些与学生完全一致。差异集中在"阶段二·确定入党积极分子"的人选产生方式与考核侧重点。

## 二、基本资格（同《细则》第五条）

年满十八岁的中国工人、农民、军人、知识分子和其他社会阶层的先进分子，承认党的纲领和章程，愿意参加党的一个组织并在其中积极工作、执行党的决议和按期交纳党费的，可以申请加入中国共产党。

## 三、教职工确定入党积极分子的额外条件（高校通行细则）

在基本资格之外，确定教职工入党积极分子一般还须具备：

1. **已递交书面入党申请书满 6 个月以上**（多校规定，如烟台汽车工程职业学院明确"已递交入党申请书时间达到6个月以上"）；
2. **具有良好的师德师风，能较好完成本职工作**（无学术不端、无违法违纪受处分记录）；
3. **积极参加集体活动**，能较好完成学校和所在单位交给的工作任务；
4. **作风正派，同事关系融洽，群众基础扎实**。

**不得确定为入党积极分子的情形**：
- 违纪违规受到处分且在影响期内的；
- 党员推荐 / 民主测评赞成率不足 50% 的；
- 违反纪律未受处分但情节较重，党组织研究认为不宜确定的。

## 四、教职工侧"阶段二·确定入党积极分子"流程

1. **党员推荐**：党支部组织党员对递交申请书且满 6 个月的人员进行推荐（实到人数须超过应到人数 2/3，赞成率超过 50%）。
2. **群团组织推优**：工会、团委等群团组织可对组织内符合条件的优秀分子推荐（填写推荐表）。
3. **支委会研究决定**：综合党团推荐结果，防止简单以票取人，由支部委员会（或支部大会）研究确定。
4. **报上级党委备案**：了解是否具备条件、手续是否齐全。
5. **指定培养联系人**：1—2 名正式党员。
6. **公示**：不少于 5 个工作日。
7. **培养考察**：党支部每半年考察一次，培养教育时间≥1年。

> 28 周岁以下青年教师：一般仍从团员中发展，可走团支部推优；28 周岁以上已退团者，直接走党员推荐 / 群团组织推优渠道。

## 五、教职工材料清单（测评对象不同，其余同学生）

- 入党申请书、个人自传、学习党的基本知识心得体会（同学生，须本人手写）
- 个人思想汇报（自批准为积极分子起每季度至少一篇）
- 入党积极分子培训考试结业证、荣誉证书复印件
- 政治审查材料：外调函（未婚函调父母，已婚含配偶），形成结论性政审材料
- **拟发展对象民主测评小结（同事 / 教职工测评）**
- **群众座谈会记录（同事座谈会，原始记录）**
- 支部鉴定
- 入党志愿书、预备党员教育考察登记表、转正申请书等

> 提示：教职工有人事档案，入党材料（《入党志愿书》、申请书、政审材料、转正申请书、培养考察材料）最终归入本人人事档案。

## 六、关键时限（同全校）

| 节点 | 时限 |
|------|------|
| 党组织同申请人谈话 | 收到申请书后 1 个月内 |
| 递交申请书至确定积极分子 | 一般满 6 个月方可推荐 |
| 积极分子培养考察 | ≥ 1 年，每半年考察一次 |
| 党委预审合格后提交支部大会 | 1 个月内（2026 细则第十九条） |
| 发展对象公示 | ≥ 5 个工作日（学校材料口径一般执行公示 7 天） |
| 发展对象集中培训 | ≥ 3 天 或 24 学时 |
| 党委审批预备党员 | 收到决议后 3 个月内（最长 6 个月） |
| 入党宣誓 | 批复后 1 个月内 |
| 预备期 | 1 年，自支部大会通过其为预备党员之日算起（可延长一次，半年至一年；不合格可取消资格） |
| 党委审批转正 | 收到转正决议后 3 个月内 |
| 整体周期 | 2.5—3 年以上 |

## 七、给江西服装学院教职工的具体建议

- **向谁交申请书**：向你所在部门归属的基层党组织递交（机关部门归属见第八节名录），须本人手写；不确定归属的，先向本部门主要负责人或所属党总支确认。
- **突出你的优势**：结合本职岗位写实绩——教学岗突出立德树人、教学建设与指导学生；管理岗突出服务师生、制度执行与专项任务；技术/教辅岗突出保障支撑、参与重大建设与应急响应表现。
- **师德红线**：高校教师入党，师德师风是一票否决项——务必无学术不端、无违纪违规受处分记录；网络行为表现也纳入政治审查（2026细则第十六条）。
- **主动靠拢**：定期向培养联系人 / 党支部汇报思想，积极参加党内活动、志愿服务，争取党员推荐与群众公认。
- **时间预期**：从递交申请书到转正通常 2.5—3 年，尽早递交、尽早进入培养考察。

## 八、江西服装学院机关党支部设置（用于确定本人向哪个支部递交申请）

机关部门教职工按所在部门归属下列机关党支部：

| 支部 | 组成部门 |
|------|----------|
| 机关第一党支部 | 党政办、质评中心、双创学院 |
| 机关第二党支部 | 党委组织部（党校）、纪检监察室、工会、妇联 |
| 机关第三党支部 | 教务处、科技产业处、学科建设与发展规划处等（现有党员 19 人，其中正式党员 18 人、预备党员 1 人） |
| 机关第四党支部 | 学工处、校团委、保卫处 |
| 机关第五党支部 | 宣传部（新闻中心） |
| 机关第六党支部 | 招生处、就业处 |
| 机关第七党支部 | 网络与信息化管理中心、图书馆、计划财务处、资产处、后勤服务中心 |
| 机关第八党支部 | 人事处、教师工作部、教师发展中心 |

> 注意：各学院另设党委 / 党总支及教工、学生党支部，学院教师向本学院教工党支部递交申请，不走机关支部。支部设置会随机构调整变动，递交前建议向本部门确认一次。

## 九、内容置信度说明

- **高置信（法规条文）**：五阶段流程、培养期 ≥1 年、公示 ≥5 个工作日、培训 ≥3 天/24 学时、审批 3 个月（最长 6 个月）、转正审批 3 个月、预备期 1 年等，均出自《中国共产党发展党员工作细则》（2026-05-11 发布）。
- **参考值（他校通行做法，需向学校核实）**："递交申请书满 6 个月方可推荐""党员推荐赞成率 > 50%"等来自多所高校实施细则，非江西服装学院公开文件明载，实际执行以党委组织部口径为准。
- **待核实**：校团委推优通知（dw.jift.edu.cn/info/1005/1158.htm）尚未核验可达性与时效。
