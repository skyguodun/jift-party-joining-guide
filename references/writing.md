# 入党文书写作骨架（申请书 / 自传 / 思想汇报）

> **使用纪律**：本文件只提供**结构、规范与句式示例**，不提供整篇可照抄的范文。申请书、自传、思想汇报均须本人手写，严禁抄袭或 AI 代写——这既是学校要求，也是 2026 年《细则》明确的处理情形（篡改、伪造材料、隐瞒入党前严重错误依规依纪处理）。

## 一、入党申请书

### 格式规范

| 项目 | 要求 |
|------|------|
| 用纸 | 16 开或 A4 方格稿纸，黑色钢笔/签字笔手写 |
| 标题 | 第一行居中"入党申请书" |
| 称谓 | 第二行顶格"敬爱的党组织："（或"敬爱的××党支部："） |
| 正文 | 另起行空两格，一般 1500—2000 字 |
| 落款 | "此致"另起行；"敬礼！"下一行顶格；右下方"申请人：×××"与日期 |
| 字迹 | 工整、无涂改、无错别字 |

### 正文六段结构

1. **开门见山表志愿**：直接写"我志愿加入中国共产党……"，表明自愿申请、接受组织考验。
2. **对党的认识**：准确引用党章表述（见下方"必须准确的表述"），不得使用过时数据（如党的年龄、党员数量）。
3. **入党动机与成长经历**：核心段落，必须写真人真事——家庭影响、亲历的重大事件、志愿服务/社会实践中的具体触动。
4. **本人的现实表现**：学业成绩、班级/团学职务、获奖、志愿服务时长；**必须写自身不足**。
5. **入党后的打算**：理论学习、学好专业、服务同学、服从组织分配。江服学生可结合专业写"用专业所学服务地方产业、传播中华优秀传统文化"。
6. **表态收尾**：暂时未获批准也不气馁，继续以党员标准要求自己。

### 必须准确的表述（不得改动字句）

> 中国共产党是中国工人阶级的先锋队，同时是中国人民和中华民族的先锋队，是中国特色社会主义事业的领导核心，代表中国先进生产力的发展要求，代表中国先进文化的前进方向，代表中国最广大人民的根本利益。党的最高理想和最终目标是实现共产主义。
>
> 党以马克思列宁主义、毛泽东思想、邓小平理论、"三个代表"重要思想、科学发展观、习近平新时代中国特色社会主义思想作为行动指南。全心全意为人民服务是党的根本宗旨。

入党誓词（现行版本，申请书可引、不可改字）：

> 我志愿加入中国共产党，拥护党的纲领，遵守党的章程，履行党员义务，执行党的决定，严守党的纪律，保守党的秘密，对党忠诚，积极工作，为共产主义奋斗终身，随时准备为党和人民牺牲一切，永不叛党。

### 第 3 段示例句式（照逻辑写自己的事，不要照抄）

> 我出生在××县的一个普通家庭，××是一名有××年党龄的老党员，他常对我说"……"。进入江西服装学院后，我参加了学院组织的××志愿服务，在××过程中，我看到身边的党员总是冲在最前面……这些经历让我认识到，入党不是一种荣誉，而是一份责任。

### 常见扣分点

网上整篇复制导致出现过时表述；通篇空话无个人经历；只写优点不写不足；时间逻辑错乱；打印后签名；AI 生成。

## 二、个人自传

自传是政治审查的比对材料，**时间线准确与信息真实比文采重要**，且与外调函、函调回函必须一致。

### 七段结构

1. **基本情况**：姓名、性别、民族、出生年月、籍贯、出生地、本人成分（学生）、文化程度、学院班级、联系方式。
2. **家庭主要成员**（建议列表格）：称谓、姓名、年龄、政治面貌、工作单位及职务。
3. **主要社会关系**：祖父母、外祖父母、已婚兄弟姐妹、关系密切的伯叔姑舅姨；有海外/港澳台关系须如实写明。

> 政治面貌只写规范表述：中共党员、中共预备党员、共青团员、群众、民主党派名称。满 28 周岁未在团内担任职务的应办理离团手续，按群众填写。

4. **个人履历（小学—大学）**："××××年××月至××××年××月，在××学校就读，证明人×××。"每段都要有证明人。
5. **思想演变过程**：按阶段写对党的认识变化，要有具体事件。
6. **奖惩情况**：如实写校级以上奖励与处分；无处分写明"无违法违纪行为，未受过任何处分"。
7. **自我评价与表态**：优点与不足，表明对内容真实性负责，落款签名。

### 常见扣分点

时间与履历空档；家庭成员信息与函调回函不一致；夸大或隐瞒（隐瞒致命）。

## 三、思想汇报

### 基本要求

- 自被批准为入党积极分子起，**每三个月至少一篇**；考察期越长篇数越多（1 年考察期通常 4 篇以上）。
- 转正环节学校要求预备期内**书面思想汇报 4 次**。
- 每篇 1000—1500 字，手写，落款日期按季度递进。

### 四段式结构

1. **引子**：点明时段与主题（"自上一季度递交思想汇报以来……现将本季度思想、学习和工作情况汇报如下"）。
2. **理论学习**：读了什么、想通了什么——写"哪句话触动了我、为什么"，不要只罗列书名。
3. **实践表现**：学习、班级/团学工作、志愿服务三块，用事实和具体数字。
4. **存在不足＋下步打算**：必须写自我批评，并请组织继续考验。

### 篇次选题建议（避免内容雷同）

| 篇次 | 侧重主题 |
|------|----------|
| 1 | 被确定为入党积极分子后的认识与打算 |
| 2 | 学习党章/党史的体会 |
| 3 | 参加志愿服务、社会实践的收获 |
| 4 | 专业学习与先锋模范作用 |
| 5 | 对照党员标准的自我剖析与整改 |

### 常见扣分点

四篇内容雷同只换日期；全篇抄理论无个人思考；只报喜不报忧；时间倒挂（写了之后才发生的事）。

## 四、转正申请书

- **提出时间**：**预备期满后**（学校明确要求，不可提前）。
- 内容结构：本人基本情况与预备期起止时间 → 预备期内履行党员义务、发挥先锋模范作用的情况 → 存在不足与改进措施 → 表明按期转正的意愿 → 落款。
- 配套材料：预备期内 4 次书面思想汇报、支部报告及横表、离校三个月以上实习/提前就业者的单位现实表现证明。
