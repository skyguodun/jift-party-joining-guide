# 江西服装学院入党流程全攻略

WorkBuddy / CodeBuddy 本地技能（Skill），覆盖从递交入党申请书到转为正式党员的完整链路。**v1.1.0**

> 本技能因主题属涉政内容，未通过 SkillHub 公开市场上架审核，以本地安装方式分发使用。

## 它能回答什么

- **流程**：五阶段 25 步骤、每个环节的时限与依据条文
- **资格**：推优入党的年龄、团龄、成绩、处分等门槛，以及"还差哪一步"
- **材料**：江服四个报批环节的完整材料清单（含学校独有的"报告及横表"）
- **写作**：入党申请书、个人自传、思想汇报、转正申请书的骨架与规范句式
- **归属**：机关第一至第八党支部由哪些部门组成，该向哪个支部递交申请
- **教职工**：与学生在渠道、考核、测评对象上的差异

## 安装

```bash
# 方式一：直接放到技能目录
git clone <本仓库> ~/.workbuddy/skills/jift-party-joining-guide

# 方式二：下载 zip 解压到 ~/.workbuddy/skills/ 下，目录名保持 jift-party-joining-guide
```

安装后，对话中直接问"江西服装学院入党流程""推优条件怎么写""入党申请书怎么开头"即可触发。

## 免责与使用纪律

- 入党申请书、思想汇报、自传等材料**须本人手写**，严禁抄袭或 AI 代写；本技能只提供结构与写法，不代写正文。
- 对篡改、伪造个人档案资料、隐瞒入党前严重错误的，依规依纪严肃处理。
- 支部设置与名额口径会随机构调整变动，递交材料前请向本部门再确认一次。
